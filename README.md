# Gamepad QoL Suite

**简体中文** | [English](README.en.md)

**Project Zomboid Build 42 的手柄体验增强套件**

把手柄玩僵尸毁灭工程时那些「别扭、卡手、只能切键鼠」的地方补齐：物品多选与快捷转移、Y 键直达面板、方向键轮盘拓展、家具旋转修复、面板信息增强……

> 全部改动都在 `GQS` 前缀的独立模块里，**不修改游戏原版 Lua，也不修改前置模组 CustomGamepadUI 的任何文件**。随时删掉文件夹即可完全卸载。

| 项目 | 说明 |
|---|---|
| 游戏版本 | Build 42.21.0（B42 专用，不兼容 B41） |
| 前置模组 | [CustomGamepadUI](https://steamcommunity.com/sharedfiles/filedetails/?id=3001154607)（必需） |
| 当前版本 | `1.5.1.50` |
| 作者 | Akatsuki_w |
| 界面语言 | 简体中文 / English |

## 这个模组解决什么问题

原版 B42 的手柄支持已经能用，但物品栏和面板操作仍然偏「键鼠思维」。常见痛点：

- 想一次把十几件战利品塞进背包，只能一件一件按 A
- 从背包挪东西到箱子，得反复切容器、反复确认
- 健康 / 建造 / 合成 / 健身面板分散在轮盘和菜单里，每次都要绕路
- 想关灯、打碎窗户玻璃，只能放下手柄去点鼠标
- **家具转完方向，一按确认又变回原来的朝向**（原版 bug，见下文）
- 建造 / 合成配方列表翻页只能一行一行往下按

这个模组就是逐条对付这些。

## 安装

### 1. 安装前置模组

本模组依赖 **CustomGamepadUI**，必须先装好并启用：

- Steam 创意工坊订阅：[CustomGamepadUI（ID 3001154607）](https://steamcommunity.com/sharedfiles/filedetails/?id=3001154607)

### 2. 安装本模组

**方式 A：从 Releases 下载（推荐）**

1. 打开 [Releases](https://github.com/akatsukiw/GamepadQoLSuite/releases) 页面
2. 下载最新版的 `GamepadQoLSuite_v<版本>_Full.zip`
3. 解压——里面已经是一个 `GamepadQoLSuite` 文件夹，**不需要改名**
4. 把它整个放进模组目录：

   ```
   Windows:  C:\Users\<你的用户名>\Zomboid\mods\
   Linux:    ~/Zomboid/mods/
   macOS:    ~/Zomboid/mods/
   ```

   放好后目录结构应该是：

   ```
   Zomboid/mods/GamepadQoLSuite/
   ├── 42/
   │   ├── mod.info
   │   └── media/
   ├── common/
   └── CHANGELOG_zh-CN.txt
   ```

**方式 B：下载源码 ZIP**

1. 在本仓库页面点 **Code → Download ZIP**
2. 解压，得到一个形如 `GamepadQoLSuite-main` 的文件夹
3. **把文件夹改名为 `GamepadQoLSuite`**（名字必须是这个，否则模组 ID 对不上）
4. 放进上面同样的模组目录

**方式 C：git clone**

```bash
cd "C:/Users/<你的用户名>/Zomboid/mods"
git clone https://github.com/akatsukiw/GamepadQoLSuite.git
```

（clone 下来的目录名天然就是 `GamepadQoLSuite`，无需改名。）

### 3. 启用模组

1. 启动游戏 → **模组** 菜单
2. 先启用 **CustomGamepadUI**，再启用 **Gamepad QoL Suite**
3. 顺序很重要：CustomGamepadUI 必须在前面（它提供本模组依赖的类与设置接口）
4. 进入存档后，到 **选项 → 模组设置** 里按需调整开关

## 详细用法

### 1. 物品多选

在背包、容器、搜寻栏的物品列表里都可以用。

| 操作 | 默认按键 | 效果 |
|---|---|---|
| 切换单件选中 | `R3`（右摇杆按下） | 选中/取消当前焦点行，同时把它记为「范围起点」 |
| 范围选择 | `L3`（左摇杆按下） | 先用 `R3` 设起点，把焦点移到终点行，按 `L3` 选中整段 |
| 全选 / 清空 | `L3` + `R3` 同时按 | **列表里有任何选中就先清空**；完全没有选中时才全选 |

细节：

- 选中状态**跨页保留**，翻页不会丢
- 移动视角、切换容器、关闭面板时自动清空选择
- 多选后按 `A` 会对所有选中物品执行动作（转移到容器、丢弃等）
- 「全选 / 清空」是严格二段式：只要还选着一件，按下去就是清空，不会「叠加全选」

### 2. X 键快捷转移

| 操作 | 效果 |
|---|---|
| 轻击 `X` 后松开 | 把**当前选中**的物品全部转移到另一侧面板的当前容器 |
| 长按 `X`（默认 200 ms） | 进入目标选择模式：用方向键挑目标容器，**松开 X 执行转移** |

- 长按阈值可在设置里调（数值越小越容易触发长按，越大越不容易误触）
- **收藏物品保护**：带星标的收藏物品只能在角色随身容器之间移动，无法被转进箱子、搜寻容器或地面。单人、联机都生效
- 只拦截 `X` 键，`L3` / `R3` 等其他按键照常透传，不会被吞

### 3. 长按 B 拖拽（默认关闭）

模拟鼠标拖拽的手感：

1. 先多选若干物品
2. 长按 `B` 达到阈值 → 出现虚拟拖动光标
3. 推动左摇杆把光标移到目标容器按钮或物品列表上
4. 松开 `B` 完成转移

短按 `B` 仍然是原版行为（展开/折叠等）。需要在设置里手动开启「启用长按 B 键拖拽转移」。

### 4. Y 键面板快捷

**Y + 方向键**（默认映射，可逐个改）

| 组合 | 默认动作 |
|---|---|
| `Y` + 上 | 打开健康面板并聚焦 |
| `Y` + 下 | 打开背包并聚焦 |
| `Y` + 左 | 打开建造面板（原版） |
| `Y` + 右 | 打开合成面板（原版） |

每个方向还能选：人物信息、健身面板、不使用。

**连续切换**：按住 `Y` 不放，先按上打开健康面板，**不松手**直接按右就切到合成面板，再按左切建造。松开 `Y` 后不会额外触发 Y 的原本动作。

**Y + 左摇杆**：站定后按住 `Y` 会锁定人物移动，推动左摇杆即可按窗口所在方向实时切换焦点，选中的窗口会显示原版绿色边框。松开 `Y` 交出焦点。若按下 Y 时摇杆已经在移动，则不会启动面板选择。

**配套提示**（自动显示，无需设置）：

- 打开 Select 轮盘并选中「建造 / 合成 / 玩家信息」时，切片文字第二行会显示 `Y + 方向键` 图标，提醒你有快捷键
- 按住 `Y` 期间，左侧图标栏对应图标右侧会浮出方向键图标，松开即消失

总开关「启用全部 Y 键增强功能」关闭后，`Y` 立刻恢复原版：按下即执行，不再等待松开。

### 5. RB 组合键

**只在世界界面有焦点、且背包/战利品窗口都关闭时生效**（窗口打开时 RB+上下 仍是原版的容器切换）。

| 组合 | 默认动作 | 可选值 |
|---|---|---|
| `RB` + 上 / 下 | 上一个 / 下一个情绪（Moodle）状态 | 不使用 / 上一个 / 下一个 |
| `RB` + 左 / 右 | 缩小 / 放大视角 | 不使用 / 放大 / 缩小 |
| `RB` + `Y` | 放大视角 | 不使用 / 放大 / 缩小 |
| `RB` + `A` | 缩小视角 | 不使用 / 放大 / 缩小 |

### 6. RT+B 退关面板

按住 `RT` 再按 `B`：

- **焦点在面板上**：只把手柄焦点交还给人物，面板保持打开
- **RT 不松开、再按一次 B**：尝试关闭所有可识别的可见面板（固定 HUD 不会关）

屏幕底部的提示文字是「**退关面板**」。

### 7. 方向键轮盘拓展

**右方向键轮盘**（可选，各有开关）

- 健身面板
- 技能面板（打开后自动把焦点切到技能页）

**上方向键轮盘**（上下文相关，附近没有目标就不显示）

| 选项 | 出现条件 |
|---|---|
| 打碎玻璃 | 身边有完好的窗户（优先取面朝方向，其次周围一格） |
| 开灯 / 关灯 | 身边有已通电的电灯开关 |
| 移除碎玻璃 | 附近有碎玻璃（原有功能） |
| 开关收音机 | 附近有收音机（原有功能） |

两个新增项各有一个独立开关（「上轮盘新增打碎玻璃」「上轮盘新增开关灯」），默认开启。

**Select 轮盘额外入口**（默认关闭）：开启后在 Select 轮盘里加入安全状态切换、玩家面板、管理员面板（仅管理员可见）、PvP / 战争管理面板。

### 8. 家具旋转修复（自动生效）

**这是本模组最重要的修复，不需要任何设置。**

原版有个长期存在的 bug：用手柄转家具，预览明明转过去了，一按确认又变回原来的朝向。看起来像「偶发」，其实由三层独立缺陷叠加而成：

1. **兜底朝向**：原版固定返回 4 个朝向索引，缺哪个就用家具自己的朝向顶上。只有南北贴图的家具转到索引 2 / 4 时，拿到的还是自己 → 预览看起来没转
2. **指针劫持**：按住放置键期间，原版**每帧**按鼠标指针相对光标中心的方位重设朝向。手柄玩家不碰鼠标，指针停在屏幕某处，于是按确认的瞬间方向被改写
3. **确认执行两次 + 缓存重置**：一次确认会调用两次创建，中间原版清空了朝向字段、缓存又把索引重置为 -1，第二次只能从贴图名反推 → 推回原朝向

修复做法：只在**真实存在贴图的朝向**之间循环；手柄操作期间忽略鼠标指针的朝向覆盖；用模组自有字段在重复执行时把方向写回。

效果：两方向、四方向家具都能正常旋转，确认后保持你看到的方向。

> 这个 bug 我们已整理成一份英文报告准备提交官方，内含原版源码行号、复现步骤与三层根因的排除过程。报告不在本仓库内，需要的话可以找作者索取。

### 9. 面板信息与特质详情

| 面板 | 增强内容 |
|---|---|
| 信息面板 | 按 `X` 展开特质详情侧栏，方向键选择特质查看说明，按有益 / 负面 / 其他分组 |
| 技能面板 | 手柄选择技能时显示「下一级经验」提示，支持 `RT` + 上下翻页 |
| 建造 / 合成面板 | `RT` + 上下翻页、`X` 收藏/取消收藏配方、`Y` 显示/隐藏所有配方或建筑版本 |
| 物品信息 | 追加物品属性、物品对比高亮 |

### 10. 健身面板增强

- 打开时自动选择当前可用的优先训练
- 按 `X` 执行训练后自动关闭面板
- **默认健身时长**：10–60 分钟，步进 10，默认 30。打开面板时自动填入，改设置立即生效
- 面板放大、进度条显示

### 11. 容器布局、翻页与排序

**布局**（设置 → 背包和战利品UI）

| 选项 | 说明 |
|---|---|
| 两栏总宽度 | 屏幕百分比。Steam Deck 或宽度小于 1600px 时建议 ≥ 50% |
| 角色物品栏高度 | 屏幕百分比。低分辨率下超过 50% 可能被裁切 |
| 搜寻栏高度 | 同上 |
| 位置布局 | 默认 / 靠左 / 靠右 / 底部居中 / 顶部居中 |

分屏模式下另有独立的宽度 / 高度设置，按每位玩家自己的屏幕区域计算。

**翻页**：`RT` + 上 / 下

- 方案 1（默认）：每次跳过 7 个物品，例如 1 → 8 → 15
- 方案 2：按当前可视区域翻到屏幕边缘，再继续按页移动
- 到达列表首尾时停在边界

**排序**：`Select` 键，共 6 档（原版 4 档 + 本模组 2 档扩展），支持「分类 + 重量降序」这类组合

### 12. 混合液体自动饮用

原版只允许纯水类液体参与自动饮水。开启后，**以水为主液体、且未污染无毒**的混合容器（水 + 酒之类）也能自动喝。

不想让某个容器参与？在物品的「液体」菜单里单独关闭它即可。

### 13. 其他杂项

| 功能 | 说明 |
|---|---|
| 禁用 B 键打碎玻璃 | 运行时移除原版「打碎玻璃」动作的 B 键绑定，防误按。不改写 InputBindings XML，Controller 设置页可能仍显示原绑定 |
| 世界地图 R3 聚焦 | 在世界地图上按 `R3` 把视野拉回玩家位置 |
| Select/Start 输入修复 | 修正按 A 切容器后焦点错位、菜单打开时焦点丢失、刷新按钮与搜索框焦点异常 |

**关于隐藏项**：少量阈值类选项（如排序双击间隔、B 键长按阈值）在面板里不显示，但值仍正常保存。需要调整时改配置文件 `Zomboid/ModOptions.ini` 即可。

## 常见问题

**Q：装好后右键菜单 / 轮盘里没有新增选项？**
A：先确认 CustomGamepadUI 已启用且排在本模组前面。轮盘新增项是**上下文相关**的——上轮盘的「打碎玻璃」要身边有完好窗户才出现，「开灯」要有已通电的开关才出现。

**Q：设置面板里找不到某项？**
A：少数阈值项被刻意隐藏（见上一节）。另外确认你打开的是 **Gamepad QoL Suite** 的面板，不是 CustomGamepadUI 的。

**Q：能同时装 CustomGamepadUI 的原始版本吗？**
A：CustomGamepadUI 本身就是前置，必须装。本模组只是接管了它的一部分设置项（布局、排序），功能不冲突。

**Q：会和其他物品栏类模组冲突吗？**
A：本模组重写了容器布局、多选状态、物品转移路径，与同样修改这些逻辑的模组可能冲突。建议先单独测试。详见下方「兼容性」。

**Q：卸载后存档会坏吗？**
A：不会。所有改动都是运行时行为，不写入存档数据。删掉模组文件夹即可完全卸载。

**Q：为什么家具旋转还是不对？**
A：确认你装的是 `1.5.1.34` 或更高版本（该版本起才有旋转修复）。另外如果同时装了其他修改放置逻辑的模组，可能互相干扰。

**Q：日志在哪？**
A：`%USERPROFILE%\Zomboid\console.txt`。本模组带有分类调试日志，默认全部关闭；排查问题时可临时打开（见下方「开发」）。

## 开发

**仓库结构**

```
GamepadQoLSuite/            <- 仓库根 = 模组根目录
├── 42/
│   ├── mod.info
│   └── media/
│       ├── lua/
│       │   ├── client/     <- 30 个 GQS 模块
│       │   ├── server/     <- 1 个服务端模块
│       │   └── shared/Translate/{CN,EN}/
│       └── ui/             <- 3 个图标
├── common/README.txt
└── CHANGELOG_zh-CN.txt
```

**约定**

- 所有自有改动使用 `GQS` 前缀文件，禁止编辑原版 Lua、CustomGamepadUI、CleanUI
- 图标类资源**不要用与上游模组同名的文件**——本模组后加载会覆盖上游图标（`1.5.1.42` 踩过这个坑，`1.5.1.50` 已修正）
- 调试日志集中在 `GQSDebugLog.lua`，18 个类别各一个开关。排查问题时把对应类别设为 `true`，收尾改回 `false`——**不要删除日志语句**

**反馈问题**

请附上：游戏版本、模组版本、完整复现步骤、`console.txt` 相关片段。若能说明是否单独启用本模组复现，会大大加快定位。
