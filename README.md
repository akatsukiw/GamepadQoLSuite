# Gamepad QoL Suite

**简体中文** | [English](README.en.md)

**Project Zomboid Build 42 的手柄体验增强套件**

把手柄玩僵尸毁灭工程时那些「别扭、卡手、只能切键鼠」的地方补齐：物品多选与快捷转移、Y 键直达面板、方向键轮盘拓展、家具旋转修复、面板信息增强……

> 本人PZ新手玩家，刚玩1个星期，很多方面没有涉及，如畜牧、农业等，还会有些面板问题，今后修改好会传创意工坊，请勿擅自上传。

## 这个模组解决什么问题

原版 B42 的手柄支持已经能用，但物品栏和面板操作仍然偏「键鼠思维」。常见痛点：

- 想一次把十几件战利品塞进背包，只能一件一件按 X。
- 键鼠能方便的选择多个箱子的物品然后快速转移到另一个箱子容器，我们手柄呢？
- 健康 / 建造 / 合成 / 健身面板在逆天的选择键轮盘里，得亏我手柄有拓展肩键，别人呢？
- 想关灯、喝水、给瓶子加水，我受够了 x 下下下 A 下下 A！
- 家具转完方向，一按确认又变回原来的朝向（原版 bug，见下文）
- 建造 / 合成配方列表翻页只能一行一行下下下下下。收藏还要动鼠标？
- 各种信息比如情绪状态信息、特质信息等需要鼠标才能查看？
- 打开电视机、动物饲料槽面板不小心就关不掉了。~~一个小面板一个 bug.~~..

| [RT+B 退关面板](#5-rtb-退关面板) | `RT` + `B` | 焦点回到人物 / 关闭所有面板。还有些面板关不掉，之后检查看看 |

| [面板信息增强](#7-面板信息与特质详情) | `X` / `Y` / `RT`+上下 | 建造合成里的配方收藏、翻页；人物信息特质详情页；技能面板经验提示和快速翻页 |
| [健身面板增强](#8-健身面板增强) | 右轮盘可快速打开 | 自动选训练、默认时长、按 X 一键执行 |
| [其他杂项](#11-其他杂项) | — | 禁误按 B 打碎玻璃、地图 R3 聚焦玩家 |

所有按键都可以在**游戏内 → 选项 → 模组设置 → Gamepad QoL Suite** 里改。

## 其他说明

- 本地分屏方案新增了单独的容器布局宽度高度数据。
- 混合液体（主要用于微分饮酒法）自动饮用，可在 mod 设置关闭。
- 拖动容器里的名称/类型/重量分割线现在会持久化，分屏和单人独立储存。
- 开启游戏内 设置 - 辅助设置 - 容器切换的方案 3（LB、RB+上/下）后，可同时兼容方案 1 的轻触 LB/RB 切换容器（mod 设置里有开关）。
- 手柄环境下官方的家具旋转 bug 修复。
- 修复官方在建造/合成面板打开最右侧的可选物品后按 B 退出报错的 bug。
- 修复 CleanUI 的随身容器选择边界行为，可通过 LB+上 快速选择最后一个物品（需把游戏辅助设置里的容器切换模式改为方案 3）。
- 修复 CleanUI 随身容器排序后手柄切换的乱序问题（不要打开 CleanUI 的搜寻容器可排序，有同样的 bug 没修）。
- 修复 CGUI 的 Start 键模拟双击输入在已装备物品处报错。

## 安装

### 1. 安装前置模组

本模组依赖 **CustomGamepadUI**，必须先装好并启用：[Workshop（ID 3001154607）](https://steamcommunity.com/sharedfiles/filedetails/?id=3001154607)。

### 2. 安装本模组

**方式 A：从 Releases 下载（推荐）**

到 [Releases](https://github.com/akatsukiw/GamepadQoLSuite/releases) 下载最新的 `GamepadQoLSuite_v<版本>_Full.zip`，解压后里面已经是一个 `GamepadQoLSuite` 文件夹，**不需要改名**，整个放进模组目录即可：

```
Windows:  C:\Users\<你的用户名>\Zomboid\mods\
Linux:    ~/Zomboid/mods/
macOS:    ~/Zomboid/mods/
```

**方式 B：下载源码 ZIP**

点 **Code → Download ZIP**，解压得到形如 `GamepadQoLSuite-main` 的文件夹，**改名成 `GamepadQoLSuite`**（否则模组 ID 对不上），再放进同样的目录。

**方式 C：git clone**

```bash
cd "C:/Users/<你的用户名>/Zomboid/mods"
git clone https://github.com/akatsukiw/GamepadQoLSuite.git
```

装好后目录结构：

```
Zomboid/mods/GamepadQoLSuite/
├── 42/
│   ├── mod.info
│   └── media/
└── common/
```

### 3. 启用模组

1. 启动游戏 → **模组** 菜单
2. **先启用 CustomGamepadUI，再启用 Gamepad QoL Suite**（顺序很重要，前置提供本模组依赖的类与设置接口）
3. 进入存档后，到 **选项 → 模组设置** 里按需调整开关

## 详细用法

### 1. 物品多选

在背包、容器、搜寻栏的物品列表里都可以用。

| 操作 | 默认按键 | 效果 |
|---|---|---|
| 切换单件选中 | `R3`（右摇杆按下） | 选中/取消当前焦点行，同时把它记为「范围起点」 |
| 范围选择 | `L3`（左摇杆按下） | 先用 `R3` 设起点，把焦点移到终点行，按 `L3` 选中整段 |
| 全选 / 清空 | `L3` + `R3` 同时按 | **列表里有任何选中就先清空**；完全没有选中时才全选 |

### 2. X 键快捷转移

| 操作 | 效果 |
|---|---|
| 轻击 `X` 后松开 | 把**当前选中**的物品全部转移到另一侧面板的当前容器 |
| 长按 `X`（默认 200 ms） | 进入目标选择模式：用方向键挑目标容器，**松开 X 执行转移** |

收藏物品只能在角色随身容器之间移动，不会被转进箱子、搜寻容器或地面。

### 3. Y 键面板快捷

| 组合 | 默认动作 |
|---|---|
| `Y` + 上 | 打开健康面板并聚焦 |
| `Y` + 下 | 打开背包并聚焦 |
| `Y` + 左 | 打开建造面板（原版） |
| `Y` + 右 | 打开合成面板（原版） |

每个方向还能选：人物信息、健身面板、不使用。

**Y + 左摇杆**：站定后按住 `Y` 会锁定人物移动，推动左摇杆即可按窗口所在方向实时切换焦点，选中的窗口会显示原版绿色边框。松开 `Y` 交出焦点。若按下 Y 时摇杆已经在移动，则不会启动面板选择。修车的时候看技能面板会很有用……

**UI 提示**：打开 Select 轮盘并选中「建造 / 合成 / 玩家信息」时，切片第二行会显示 `Y + 方向键` 图标；按住 `Y` 期间，左侧图标栏对应图标右侧也会浮出方向键图标，松开即消失。

总开关「启用全部 Y 键增强功能」关闭后，`Y` 立刻恢复原版：按下即执行，不再等待松开。

### 4. RB 组合键

**只在世界界面有焦点、且背包/战利品窗口都关闭时生效**（窗口打开时 RB+上下 仍是原版的容器切换）。

| 组合 | 默认动作 | 可选值 |
|---|---|---|
| `RB` + 上 / 下 | 上一个 / 下一个情绪（Moodle）状态 | 不使用 / 上一个 / 下一个 |
| `RB` + 左 / 右 | 缩小 / 放大视角 | 不使用 / 放大 / 缩小 |
| `RB` + `Y` | 放大视角 | 不使用 / 放大 / 缩小 |
| `RB` + `A` | 缩小视角 | 不使用 / 放大 / 缩小 |

### 5. RT+B 退关面板

按住 `RT` 再按 `B`：

- **焦点在面板上**：只把手柄焦点交还给人物，面板保持打开
- **再按一次**：尝试关闭所有可识别的可见面板（固定 HUD 不会关）
- 有些面板还是无法关闭，排查 ing

### 6. 方向键轮盘拓展

**右方向键轮盘**（可选，各有开关）：健身面板、技能面板（打开后自动把焦点切到技能页）。

**上方向键轮盘**（上下文相关，附近没有目标就不显示）：

| 选项 | 出现条件 |
|---|---|
| 打碎玻璃 | 身边有完好的窗户（优先取面朝方向，其次周围一格） |
| 开灯 / 关灯 | 身边有已通电的电灯开关 |
| 移除碎玻璃 | 附近有碎玻璃（CGUI 原有功能） |
| 开关收音机 | 附近有收音机（CGUI 原有功能） |
| 放下穿着背包 | 身上有背包，和键盘快捷键放下背包同功能 |

两个新增项各有一个独立开关（「上轮盘新增打碎玻璃」「上轮盘新增开关灯」），默认开启。

**Select 轮盘额外入口**（CGUI 功能，默认关闭）：开启后在 Select 轮盘里加入安全状态切换、玩家面板、管理员面板（仅管理员可见）、PvP / 战争管理面板。

### 7. 面板信息与特质详情

| 面板 | 增强内容 |
|---|---|
| 信息面板 | 按 `X` 展开特质详情侧栏，方向键选择特质查看说明，按有益 / 负面 / 其他分组 |
| 技能面板 | 手柄选择技能时显示「下一级经验」提示，支持 `RT` + 上下快速翻页 |
| 建造 / 合成面板 | `RT` + 上下翻页、`X` 收藏/取消收藏配方、`Y` 显示/隐藏所有配方或建筑版本 |

### 8. 健身面板增强

- 打开时自动选择当前可用的优先训练
- 按 `X` 执行训练后自动关闭面板
- **默认健身时长**：10–60 分钟，步进 10，默认 30。打开面板时自动填入，改设置立即生效
- 面板放大、进度条显示

### 9. 容器布局、翻页与排序

**布局（CGUI 功能）**：两栏总宽度、角色物品栏高度、搜寻栏高度、位置布局（默认 / 靠左 / 靠右 / 底部居中 / 顶部居中）。低分辨率下高度超过 50% 可能被裁切；分屏模式下另有独立的宽度 / 高度设置，按每位玩家自己的屏幕区域计算。

**翻页**：`RT` + 上 / 下

- 方案 1（默认）：每次跳过 7 个物品，例如 1 → 8 → 15
- 方案 2：按当前可视区域翻到屏幕边缘，再继续按页移动
- 到达列表首尾时停在边界

**排序**：`Select` 键，共 6 档（原版 4 档 + 本模组 2 档扩展），支持「分类 + 重量降序」这类组合。

### 10. 混合液体自动饮用

原版只允许纯水类液体参与自动饮水。开启后，**以水为主液体、且未污染无毒**的混合容器（水 + 酒之类）也能自动喝。不想让某个容器参与，在物品的「液体」菜单里单独关闭即可。

### 11. 其他杂项

| 功能 | 说明 |
|---|---|
| 禁用 B 键打碎玻璃 | 运行时移除原版「打碎玻璃」动作的 B 键绑定，防误按。不改写 InputBindings XML，Controller 设置页可能仍显示原绑定 |
| 世界地图 R3 聚焦 | 在世界地图上按 `R3` 把视野拉回玩家位置 |

## 模组设置面板

**选项 → 模组设置 → Gamepad QoL Suite**，分组：背包和战利品UI、容器内操作优化、按键功能拓展、RB 组合键功能、RT+B 焦点恢复、方向键轮盘拓展、面板增强、Select 键排序、其他杂项。

CustomGamepadUI 面板里的「Inventory and Loot」四项和排序设置已被本模组接管并隐藏，**在上游面板里调那几项不会生效**，请在本模组面板里调。少量阈值类选项（排序双击间隔、B 键长按阈值）不显示但值仍保存，需要改就编辑 `Zomboid/ModOptions.ini`。

## 常见问题

**Q：装好后轮盘里没有新增选项？**
A：先确认 CustomGamepadUI 已启用且排在本模组前面。上轮盘新增项是**上下文相关**的——「打碎玻璃」要身边有完好窗户，「开灯」要有已通电的开关。

**Q：设置面板里找不到某项？**
A：少数阈值项被刻意隐藏（见上一节）。另外确认你打开的是 **Gamepad QoL Suite** 的面板，不是 CustomGamepadUI 的。

**Q：会和其他物品栏类模组冲突吗？**
A：本模组重写了容器布局、多选状态、物品转移路径，与同样修改这些逻辑的模组可能冲突，建议先单独测试。

**Q：卸载后存档会坏吗？**
A：不会。所有改动都是运行时行为，不写入存档数据，删掉模组文件夹即可完全卸载。

**Q：日志在哪？**
A：`%USERPROFILE%\Zomboid\console.txt`。模组自带分类调试日志，默认全部关闭。

**Q：遇到 bug 怎么反馈？**
A：请附上游戏版本、模组版本、复现步骤，以及 `console.txt` 里相关的几行。能说明是否单独启用本模组就能复现，会大大加快定位。

## 兼容性

- **游戏版本**：Build 42.21.0，其他版本未测试
- **必需前置**：CustomGamepadUI（Workshop 3001154607）
- **不建议共存**：目前测试了CleanUI，其他重写物品栏布局、多选状态或物品转移的模组可能有哦问题（可能重复拦截同一按键）。
- **多人**：包含一个服务端模块（混合液体自动饮用的液体类型同步），联机需要客户端与服务端都安装
- **不修改**：游戏原版 Lua、CustomGamepadUI 的 Workshop 文件、CleanUI

## 已知限制

- 破损窗户的名称偶尔不显示
- 外接混合液体水源的识别尚未完整实测
- 上轮盘新增项依赖附近目标，空旷处不出现属正常现象
